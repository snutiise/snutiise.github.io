I set up an environment to try Electron, which I had only heard about for a long time.

## What is Electron?

<img src="https://upload.wikimedia.org/wikipedia/commons/3/3f/Electron_0.36.4_Icon.png" alt="" loading="lazy" decoding="async" width="256" height="256">
>Electron (formerly Atom Shell) is an open-source framework developed by Cheng Zhao and now developed by GitHub. It enables the development of desktop graphical user interface applications using front-end and back-end components originally developed for web applications: the Node.js runtime for the back end and Chromium for the front end. Electron is a major GUI framework behind several notable open-source projects, including GitHub's Atom, Microsoft's Visual Studio Code source code editor, the Light Table IDE, and the freeware desktop client for the Discord chat service. *(translated from Korean)*

The versions of node and npm I was using were old, so I updated them before installing Electron.

{% highlight bash %}
#node update
$ sudo npm install -g n
$ sudo n latest

#version check
$ node -v
$ npm -v
{% endhighlight %}

After that, I downloaded quick-start from git and ran it.

{% highlight bash %}
# Clone the repository
$ git clone https://github.com/electron/electron-quick-start

# Move into the repository
$ cd electron-quick-start

# Install the dependencies and run
$ npm install && npm start
{% endhighlight %}

But when I ran npm install as above, a permission error occurred!

So I looked at the related issues and ran the install as below, and the permission error no longer occurred.

{% highlight bash %}
$ sudo npm install electron --unsafe-perm=true --allow-root
{% endhighlight %}

However, a problem occurred where electron stopped during node install.js.

So I checked the stuck on postinstall issues, and it turned out it was not stuck; it was just taking a long time because of the connection speed.

In the end, I decided to add the --verbose option again and wait patiently.

<a href="{{ "/assets/img/2018-01-15-5.png"}}"><img src="{{ "/assets/img/2018-01-15-5.png"}}" alt="End of the npm install --verbose log. electron@1.7.10 is added and it ends with added 152 packages in 3.479s" loading="lazy" decoding="async" width="1014" height="220"></a>

After waiting about 8 minutes, the installation completed!

Then I ran npm start!

<a href="{{ "/assets/img/2018-01-15-6.png"}}"><img src="{{ "/assets/img/2018-01-15-6.png"}}" alt="The Electron Hello World! window running on top of VS Code. It says it uses Node.js 7.9.0, Chromium 58.0.3029.110, and Electron 1.7.10" loading="lazy" decoding="async" width="1920" height="1080"></a>

It ran normally.

## Electron API Domes

Now let's install the API live demo!

{% highlight bash %}
$ git clone https://github.com/electron/electron-api-demos.git

$ cd electron-api-demos

$ sudo npm install --unsafe-perm=true --allow-root

$ npm start
{% endhighlight %}
