Now that the Electron development environment is set up, let's build a simple desktop app to test it!

The app I will build while studying Electron is a file-sharing app.

I switch between Linux and Windows when developing, so I needed a simple file-sharing system between different operating systems.

So I decided to build one this time!

First, let's copy main from electron-quick-start as it is!

{% highlight javascript %}
function createWindow () {
  // Create the browser window.
  mainWindow = new BrowserWindow({width: 800, height: 600, icon: path.join(__dirname, 'app/img/icon.png')});

  // and load the index.html of the app.
  mainWindow.loadURL(url.format({
    pathname: path.join(__dirname, 'app/upload.html'),
    protocol: 'file:',
    slashes: true
  }));

  // Open the DevTools.
  // mainWindow.webContents.openDevTools()

  // Emitted when the window is closed.
  mainWindow.on('closed', function () {
    // Dereference the window object, usually you would store windows
    // in an array if your app supports multi windows, this is the time
    // when you should delete the corresponding element.
    mainWindow = null;
  });
  const menu = electron.Menu.buildFromTemplate(template);
  mainWindow.setResizable(false);
  mainWindow.setMenu(menu);
}

Resizing is not needed, so I set it to false and made a suitable icon and set its path.

Now let's write the js part that sends the uploaded data!

{% highlight javascript %}
dropbox.ondrop = function (e) {
    e.preventDefault();
    let data = e.dataTransfer;
    let file = new FormData();
    flag=false;
    for (let i = 0; i < data.files.length; i++) {
        file.append('file', data.files[i]);
        if(i==data.files.length-1) flag=true;
    }
    if(flag)
    $.ajax({
        url: 'http://sodeok.xyz:8002/upload',
        type: 'POST',
        data: file,
        cache: false,
        contentType: false,
        processData: false,
        xhr: function() {
            var myXhr = $.ajaxSettings.xhr();
            if (myXhr.upload) {
                myXhr.upload.addEventListener('progress', function(e) {
                    if (e.lengthComputable) {
                        $('progress').attr({
                            value: e.loaded,
                            max: e.total
                        });
                    }
                } , false);
            }
            return myXhr;
        },
        success:function(data){
            if(data=="ok")
            $('progress').attr({
                value: 0,
                max: 0
            });
        }
    });
};
{% endhighlight %}

For each file that comes in through drag and drop, I put it into FormData and send it to the server!

Now let's write a script that fetches the download list and displays it.

{% highlight javascript %}
window.$ = window.jQuery = require('jquery');
$(document).ready(function(){
    $.ajax({
        url: 'http://sodeok.xyz:8002/list',
        type: 'POST',
        success:function(data){
            if(data!="[]"){
                let json=JSON.parse(data);
                for(let i=0;i<Object.keys(json).length;i++){
                    let list="<a href='http://sodeok.xyz:8002/download/"+String(json[i]["code"])+"'><div class='file'><img src='img/file.png' /><span>"+ String(json[i]["filename"]) + "</span></div></a>";
                    $("#dropboxDownload").append(list);
                }
            }
            else $("#dropboxDownload").html("<h2>공유 파일이 존재하지 않습니다!</h2>");
        }
    });
});
{% endhighlight %}

I made it receive only the download code from the server, so that connecting to the download/+code url downloads the file.

So when appending to dropboxDownload, it also just connects with an a tag.

To avoid a bare, text-only look, I also insert a file image.

The server also distinguishes extensions when saving, so showing a different image for each extension would be cleaner. But it's a hassle right now, so I'll skip it!

Finally, I should try deploying it.

For deployment, I used electron-packager, a third-party tool.

{% highlight bash %}
$ npm install --save-dev electron-packager
{% endhighlight %}

Now let's add a script to package.json!

{% highlight bash %}
"build": "electron-packager . dropbox --out=build-out --asar --overwrite --platform=linux --arch=x64"
{% endhighlight %}

The --out option sets the folder to deploy to, and the --asar option packs the code into asar on deployment so that it is not exposed.
(Electron reportedly can read the asar format without unpacking it.)

The --platform=linux --arch=x64 options are the platform and the architecture bits, respectively.

I use 64-bit Ubuntu, so I set Linux and the x64 architecture.

For the platform, it is darwin for Mac, win32 for Windows, and linux for Linux.
