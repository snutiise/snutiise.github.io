    1. 4세대+28 — 홈믹서 랭킹 스코어러 삭제, value model이 공유 crate 하나로 수렴 — X

    자료 xai-org/x-algorithm@44d37eb — GitHub 공개 소스코드, 2026-09-24, +2,569/−2,257 (파일 62). 어제 1b3fec20 커밋이 vm-ranker 프로세스에 xai_value_model::compute_value_scores()를 인라인으로 붙였고, 오늘은 그 shared crate가 실제 파일로 공개됐다.

    배경 X의 For You 랭킹은 Phoenix가 예측한 24개 참여 확률(favorite·reply·retweet·dwell·report ...)을 가중합해서 하나의 스칼라 점수를 얻은 뒤 여기에 작성자 다양성·OON(out-of-network) 배수·새-작성자 부스트를 곱하는 구조다. 이 계산은 두 곳에서 일어난다 — 홈믹서(Rust, home-mixer)와 그 뒤에 붙는 vm-ranker(별도 gRPC 서비스, DPP 다양성과 rank server 역할). 두 프로세스가 같은 수식을 두 벌 구현하면 미러가 어긋나는 것을 매번 사람이 잡아야 한다. 어제 커밋에서 xai_value_model 이름의 shared crate가 등장하기 시작했고, 오늘 그 crate가 실제 파일 6개로 공개되면서 홈믹서의 팻 스코어러(ranking_scorer.rs, 1,255줄)가 통째로 삭제됐다. 어느 프로세스가 어떤 파라미터를 쓰는지, 파라미터 미러가 몇 개인지 세는 관행이 이 커밋으로 정리된다.

    pub fn merge_retweet_verdict(retweet: Verdict, source: &Verdict) -> Verdict {
    match (&retweet, source) {
        (_, Verdict::Withheld(_)) => source.clone(),
        (Verdict::Withheld(_), _) => retweet,
        (
            Verdict::Shown {
                media: None,
                engagement: None,
            },
            _,
        ) => source.clone(),
        _ => retweet,
    }
}
