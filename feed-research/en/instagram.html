⚠ Every claim in this file that relies on a system card is a snapshot read on 2026-08-09. A system card is the document Meta publishes on its Transparency Center for each surface to describe an AI system. The full caveat is written once, in the "Validity period of system card quotes" section of facebook.md.

Compared with Facebook, Instagram is published in far more detail. The only formula Facebook published is the 2021 linear combination. Summary

Instagram documented Explore, Feed and Reels Chaining as separate AI systems, and as of the system cards read on 2026-08-09, the candidate counts per stage are 1500→100 for Explore, 700→500 for Feed, and ~100 for Reels Chaining verified (candidate counts by stage). It disclosed a multiplicative form in 2020, an additive form in 2023, and a multiplicative penalty in 2025, each used for a different problem verified (three combination forms). As of the 2026-10-20 paper, the Feed late-stage score is a sum that separately weights the original prediction and its increment over the viewer, item and request baselines, and this structure has run in production for almost 1 year verified (Feed value model).

Candidate generation (retrieval)

As of the system cards, Explore fetches up to 1500 and passes the top 100 to the next stage, while Feed picks about 700 and scores about 500 for relevance verified (candidate counts by stage). According to the 2023 Explore post, retrieval mixes four kinds of sources with tunable weights verified (source types). The same post gives the ability to cache embeddings as its reason for choosing two-tower (a model that computes the user-side and item-side embeddings separately) verified (two-tower). The 2020 post also publishes an actual query written in the retrieval DSL verified (retrieval DSL).

According to the system card, Explore fetches up to 1500 and passes the top 100 to the next stage verified. 4 source types and tunable weights

Explore's retrieval uses four kinds of sources together and gives each source a tunable weight verified Scaling the Instagram Explore recommendations system, 2023-08-09.

  • There are four source types verified same post.
    • "heuristics (e.g., trending posts)"
    • "more sophisticated ML approaches"
    • "real-time (capturing most recent interactions)"
    • "pre-generated (capturing long-term interests)"
  • The four sources are used together and mixed with tunable weights verified same post: "we utilize all these mentioned source types together and mix them with tunable weights"
  • This sentence is a statement that explicitly says per-source weights exist as tuning parameters. For Facebook Feed, there is no primary source even for a per-source breakdown of candidate counts (facebook.md).
  • The structure is the same as X listing 11 sources in code in home-mixer (the service that bundles candidate collection and ranking for the X For You feed); only the numbers are undisclosed inferred.

The reason for choosing two-tower is the cache

The 2023 Explore post gives the ability to cache user embeddings and item embeddings as the reason for using two-tower verified: "user and item embeddings can be cached, making inference for the Two Tower model extremely efficient".

  • The training objective is to predict engagement events as a similarity between the user embedding and the item embedding verified same post: "to predict engagement events (e.g., someone liking a post) as a similarity measure between user and item embeddings".
  • It names FAISS and HNSW as examples of ANN (approximate nearest neighbor search) libraries verified same post: "e.g., FAISS, HNSW, etc".

Facebook's connected-content retrieval has no ANN at all. It ends with a lookup of the friend graph (facebook.md). Instagram, by contrast, has a corpus on the scale of billions because Explore is a non-connected (recommendation) surface to begin with. That is why EBR (embedding-based retrieval) is a core component. This difference is likely the root cause of the gap in retrieval literature volume between the two services inferred.

Retraining cadence — hourly

The 2023 Explore post says models can be retrained (fine-tuned) every hour as soon as new data arrives verified: "we can re-train (fine-tune) our models every hour as soon as we have new data"

inferred The reason for choosing two-tower (the item tower can be cached) and hourly fine-tuning are two aspects of the same design. Updating only the item tower output means the index does not have to be rebuilt in full. Details are in topics/model-freshness.md.

retrieval DSL — real queries are published

In its 2020 post, Instagram published an actual query written in the retrieval DSL verified Designing a Constrained Exploration System (Amogh Mahapatra, 2020-12-10). The query takes accounts the user liked as seeds, expands to similar accounts, filters those accounts' media by a model score, ranks them, and interleaves them seed by seed verified.

The same post also appears on engineering.fb.com under a different title, How Instagram suggests new content. Take care not to count the same post as two citations.

user
.let(seed_id=user_id)
.liked(max_num_to_retrieve=30)
.account_nn(embedding_config=default)
.posted_media(max_media_per_account=10)
.filter(non_recommendable_model_threshold=0.2)
.rank(ranking_model=default)
.diversify_by(seed_id, method=round_robin)

Four things can be read from this one query block.

  • The basic unit of retrieval is seed-based expansion verified. It takes accounts the user liked (up to 30) as seeds and expands to similar accounts with account_nn.
  • The per-account media cap is a parameter verified.
    • max_media_per_account=10
  • The filter is a model threshold verified. It is the only numeric evidence that a policy filter is a score threshold rather than a rule.
    • non_recommendable_model_threshold=0.2
  • Diversity sits in the retrieval stage verified. It is round-robin per seed account. Facebook only writes that diversity is in pass 2 (after ranking).
    • diversify_by(seed_id, method=round_robin)

There are 3 seed sources, and they have a priority order verified.

  • H is a seed from Home Feed verified.
  • R is a seed from other recommendation surfaces such as Explore, Reels, and Shopping verified.
  • F is a backup such as personalized graph exploration verified.
  • The merge order puts H first, followed by R and F verified: "The final merge order is as follows: H >> R > F."
  • When training the candidate selection model, a constraint keeps the overall distribution from drifting away from Home-based sources verified: "the overall distribution is not skewed away from Home-based sources".

inferred The "constrained" in this post's title means a constraint that matches the Home Feed distribution, not an exploration bandit. The body never mentions Thompson sampling, bandits, or an exploration budget, and instead says it matches the media type distribution and freshness to Home Feed.

Ranking

Instagram disclosed that it uses three combination forms for different problems (three combination forms). As of the 2026-10-20 paper, the Feed late-stage score is a sum that separately weights the original prediction and the increment over the baseline, and the weights are tuned by online Bayesian optimization verified (Feed value model). As of the system cards, prediction heads differ by surface verified (prediction heads). As of the 2025 post, there are more than 1,000 production models, with a separate MTML (multi-task multi-label) model for each surface and component verified (model operating scale).

Three combination forms — the biggest difference from Facebook

Instagram disclosed that it uses three combination forms for different problems. The only combination Facebook published is linear. Facebook's formula is Vijt = Σ w·Y, with details in facebook.md.

  • (1) Multiplicative form (2020, Suggested Posts) verified Designing a Constrained Exploration System, 2020-12-10.

    Value(Post) = (probability_like)^weight_like * (1- probability_not_interested)^weight_see_less

  • (2) Additive form with a negative term (2023, Explore) verified Scaling the Instagram Explore recommendations system, 2023-08-09.

    Expected Value = W_click * P(click) + W_like * P(like) – W_see_less * P(see less) + etc.

  • (3) Multiplicative diversity penalty (2025, Notifications). Source: A New Ranking Framework for Better Notification Quality on Instagram, 2025-09-02.

    Score(c) = R(c) × D(c)
D(c) = ∏_{i=1..m} (1 - w_i · p_i(c))
p_i(c) = max_{h ∈ H} sim_i(c, h)
    • ⚠ Unlike (1) and (2), these three lines are not verbatim. In the original the formulas are rendered as LaTeX images and are not in the body text; the formulas above are a transcription of those images observed 2026-08-09.
    • However, the components are supported by the body prose verified: "the product of its base ranking score and a diversity demotion multiplier", "D(c) ∈ [0,1] is a penalty factor…"
    • Details are in ../topics/feed-diversity.md.
    • As for the symbols, R(c) is base relevance and D(c) ∈ [0,1] is the penalty.
    • H is the recent send history, w_i ∈ [0,1] is the per-dimension strength, and τ_i is the similarity threshold.
    • In the baseline implementation, p_i(c) is 1 if the similarity exceeds the threshold and 0 otherwise: "equals 1 if the similarity exceeds a threshold τ_i and 0 otherwise".
    • There are 4 dimensions: content / author / notification type / product surface.

(1) and (2) are on different surfaces, and there is no direct evidence of a switch from multiplicative to additive. However, a structural difference between the two forms is real inferred.

  • ⚠ (1) and (2) are on different surfaces. (1) is Suggested Posts (non-connected content shown at the end of Home Feed), and (2) is Explore.
    • There is no direct evidence that "Instagram switched from multiplicative to additive."
    • However, given the 3-year gap, the shared in-house literature lineage, and the fact that the sources in (2) include the successor system of (1), there is room to read it as a change of direction inferred.
  • The structural difference is real inferred. The multiplicative form gives negative signals a veto, while the additive form gives them an exchangeable cost.
    • In the multiplicative form, value drops to 0 when P(not_interested) → 1. It is effectively a hard veto.
    • In the additive form, however large the negative term is, the other terms can be larger.
  • Taking the log of the multiplicative form's exponents weight_like and weight_see_less makes it linear, so it ends up as the Σ w·log P form. That is, it is the same as Facebook's Σ w·P in being a "linear combination", and the only difference is whether P or log P is used inferred.
  • Feed's own combination form was first disclosed in the 2026-10-20 paper. It adds an increment term to the additive form, so it is an extension of (2), not a new form inferred. The basis is that the base formula is a Σ w·p weighted sum (Feed value model).
  • (3) applies diversity as a multiplicative penalty. facebook.md says "Meta does not publish its diversity algorithms (MMR/DPP)".
    • However, on the Instagram notifications side, a max-similarity penalty of the MMR family was published as a formula. MMR is a greedy re-ranking approach that reflects the distance to already selected items in the score.
    • It comes with the caveat that it is notifications, not the feed, but it is the most specific diversity disclosure across all of Meta.

Detailed comparisons are in topics/multi-task-ranking.md and topics/feed-diversity.md.

How weights are set — Facebook uses surveys, Instagram uses optimization

Instagram's 2020 post says the weights are calibrated with offline session replay and online Bayesian optimization verified. The 2023 post names Bayesian optimization and offline tuning as the two popular approaches to parameter tuning verified. The 2026-10-20 paper says the weights of the Feed value model are adjusted by online Bayesian optimization against a few north-star metrics verified (Feed value model).

  • The 2020 post's wording is as follows verified: "offline replay over user sessions and b) online Bayesian optimization"
  • The 2023 post's wording is as follows verified: "There are two popular approaches to parameters tuning: Bayesian optimization and offline tuning."
    • "replay" appears 0 times in this post (full text checked 2026-08-09).

For the same role, Facebook writes that weights are "set by surveys" (facebook.md, topics/survey-signals.md). The same company disclosed completely different answers to the same problem. In practice it likely uses both with only different emphasis, but at the level of published sentences they are clearly different inferred.

Feed value model — the original prediction and the increment are weighted separately

As of the 2026-10-20 paper, Instagram Feed's late-stage ranking scores candidates with a weighted sum of engagement predictions verified. Each prediction mixes in baselines that are laid down regardless of the candidate, such as viewer habit, item popularity and the candidate composition of the request, so Instagram keeps the original prediction and adds the increment over the baseline as a term with its own weight verified. Only format bias is removed from the training label, not through a score term verified. This structure ran in Feed production for almost 1 year and has also been released to Reels and Threads verified.

  • The scoring formula adds an original-prediction term and an increment term, weighted separately for each signal verified — arXiv 2610.27423 (paper, 2026-10-20). All 26 authors have @meta.com email domains.

    • The previous formula is s(c) = Σ_j w_j p_j(c), and the changed formula is s(c) = Σ_j [w_j^r p_j(c) + w_j^i Δ_j(c)].
    • The targets are MainRank, which orders most of the feed, and TopRank, which fills the top of the session, and each scores hundreds of candidates per request verified.
    • The deployed VM also multiplies some groups of terms, but the paper does not cover that structure verified.

  • The increment term is expressed by one operator that compares the prediction with one of three kinds of baseline verified — same paper §3.

    • The viewer baseline is that viewer's past action rate, the item baseline is item popularity, and the request baseline is prediction statistics over the candidates of the same request.
    • The general form is Δ = m(p,b)[σ(k·d(p,b)) − shift], and the deployed forms are three: p σ(logit p − logit b), m σ(ŷ − b) and max(0, p − b), all with shift 0.
    • Feed's like prediction has a rank correlation of 0.69 with the viewer's own past like rate verified.

  • It writes that the original prediction term is not removed because the baseline is also a second signal that carries real engagement verified — same paper §1.

    "The baseline is not a defect but a second signal that needs its own weight (§3). A habitual liker's likes are real engagement, and a broadly loved post deserves reach." — arXiv 2610.27423 (paper), 2026-10-20

  • Format bias is removed from the label instead of through a score term verified — same paper §4.4.

    • A positive requires dwell time above p75 within buckets split by length for videos, card count for carousels, and OCR word count for photos.

  • In an experiment that split each of the 6 deployed terms into four arms (both terms off, original term only, increment term only, both), the arm with both terms generally won verified — same paper §6.

    • Each arm was allocated 3% of traffic, and measurement covers the same 7-day window.
    • In 11 of the 13 pairs judged, the both-terms arm led both single-term arms on the point estimate. Of 26 direct contrasts, 17 were significantly favorable and 1 (impressions) was significantly unfavorable.
    • The paper itself writes that the single-term arms were not retuned, so it did not test whether a retuned single-term VM could catch up.

  • Outside Feed, Reels released the same operator in both early-stage and late-stage verified — same paper §8. The status of Threads and Facebook is in threads.md and facebook.md.

  • The paper concludes that the offline diagnostic (correlation between prediction and baseline) should be used only to screen candidate signals, not to rank them verified — same paper §7. One experimented term ranked 9th of 10 on the same axis in the offline diagnostic.

The 1st stage is a distillation of the 2nd stage

Explore's 1st stage ranker is trained to predict the output of the 2nd stage ranker, not user behavior verified 2023 post: "We train the first stage ranker to predict the output of the second stage with the label: PSelect = { media in top K results ranked by the second stage}"

  • The early stage ranker's label is not user behavior but whether an item is in the late stage ranker's top K. Facebook's pass 0 says only "high recall" and has no label definition.
  • By model, the early stage is a two-tower verified.
  • The late stage is an MTML neural network that predicts the probabilities of several engagement events such as click and like verified: "multi-task multi label (MTML) neural network model", "the probability of different engagement events (click, like, etc.)".

Prediction heads — they differ by surface (all verified, verbatim)

Instagram uses different prediction heads on each surface verified. For example, Feed has heads dedicated to the first post, Reels Chaining has an audio reuse head, and Stories has a head that predicts whether the author is family or a close friend verified.

⚠ We could not settle the total count. For Feed, Stories, Reels Chaining, and Suggested Accounts, the list extracted from the card and the count the card states do not match. So the list below should be read only as a list of confirmed items, and should not be compared directly with Facebook Feed's 10.

  • IG Feed (ig-feed, 2026-06-29) verified: carousel completion / "How likely you are to enjoy this post" / skip / dwell time on the author's profile / share via DM / dwell time on the post / first-post skip / first-post dwell over 10 seconds / turn video sound on / "How likely the first post you see is to keep you spending time in your Feed during this session"
    • There are 3 heads dedicated to the first post (skip / 10 seconds / session retention). This means slot 1 of the slate (the set of posts shown at once) is treated as a separate optimization problem inferred. Facebook cards have no such position-specific heads, and position appears only as a feature.
    • "Session continuation" is a prediction target. It is a head that directly predicts session length rather than single-item engagement.
  • IG Explore (ig-explore, 2026-06-22) verified: follow probability / watch over 5 seconds / watch over 95% of the video / 'Not Interested' click / comment / like / reshare / "How likely you click and also engage with a post" / save / "How likely you are to click one of the short, squared post in Explore to view it in full screen"
  • IG Reels Chaining (ig-reels-chaining, 2025-11-11) verified: audio reuse ("use the audio from a reel you're viewing in one you create") / watch under 3 seconds / "click 'Interested'" / comment / watch longer than 95% of viewers of reels of the same length / click on a vertical reel in Explore / reshare / share outside Instagram / follow
    • The card's How likely you are to watch more of a reel than 95% of users who watched reels of the same length head predicts not absolute watch time but a percentile relative to the viewer distribution of reels of the same length.
    • This removes length bias in the label definition; the problem Facebook handles with upper-bound clipping for external article dwell time (facebook.md) is solved by Instagram with quantile normalization inferred.
    • Audio reuse is a prediction target. It sets inducing creation, not consumption, as a ranking goal. No other head like this appears anywhere in Meta's documents.
  • IG Stories (ig-stories, 2025-09-18) verified: top-of-feed story click / question-response interaction / How likely it is that you and the story's author are family or good friends / reply click / like sent / profile entry from the viewer / reel effect save / swipe to next story / exit from current story / poll and slider response
    • "Whether they are family or close friends" is a prediction head. The relationship classifier itself enters as a multi-task head.
    • Facebook cards have "strong intent to interact with a connection", but that is a behavior prediction, while this head is a prediction of the relationship itself.
  • IG Feed Recommendations (ig-feed-recommendations, 2026-06-29) verified: "How informative a post is" / 'Interested' click / Reels dwell time after clicking a reel in the home feed / feed scroll duration after viewing the top post / scroll to next post / author profile click / comment click / first-post skip / reel full-screen click / audio on
    • The card's How long will the user spend in reels after clicking into a reels post in home feed head predicts dwell time after moving to another surface. It is direct evidence that Feed ranking puts Reels consumption into its objective function.
  • IG Suggested Accounts (ig-suggested-accounts, 2025-03-07) verified: content view after follow / follow through to follow-back / follow / profile visit after follow / follow-back
    • Follow-back probability is a separate prediction head. It sets forming a mutual connection, not a one-way follow, as the goal.

Actual feature names (excerpt, all verified verbatim)

The system card also states the features used in ranking in plain sentences verified. Examples are a feature that counts only behavior inside Explore, a binary feature for session state, and a negative-signal feature that lists the authors of reels watched for less than 3 seconds.

  • Explore has a feature family that aggregates only behavior inside Explore verified.
    • "The amount of time you've spent on Explore viewing posts from post's author in recent past"
    • "How many times you've seen short, squared reel in Explore"
    • "How many follows button clicks received on a post in Explore"
  • Reels Chaining features include a session-state feature, a negative-signal feature, and a country-level aggregate feature verified.
    • Session state is used as a binary feature: "Whether or not you've been viewing reels for more than 15 seconds"
    • Negative signals are kept as an author list: "The authors of reels you've spent less than three seconds watching"
    • There is a feature aggregated at the country level: "How much time has viewers from your country spent on this reel"
  • Feed Recommendations has a ratio feature verified: "The ratio of engagement counter to vpvd". We infer that vpvd belongs to the video play view duration family.
    • It also has device platform and app opens in the last 7 days features: "What is the device platform e.g. ios, android", "How many times you've opened the app in the last 7 days"
  • Feed features include ones covering content type, recency window, amount of text overlaid on an image, and user segment verified.
    • The output of a content-type classifier is used as a feature: "Whether the post is informative content (news, product reviews, tutorials, how-tos)"
    • The recency window is 90 days: "How recently the post was created (within 90 days)"
    • It looks at the amount of text overlaid on an image: "Whether it's a photo and how much text is overlaid on it"
    • A user segment is used as a feature: "Which Reels-watch-time group you fall into"
  • Stories features use both the average and the maximum verified: "The average and maximum amounts of time you've spent viewing stories". This appears to be used for within-user normalization inferred.

Mosseri's per-surface signal order — a form of disclosure Facebook does not have

Mosseri disclosed the ranking signals for Feed, Explore, and Reels in order of importance, while for Stories he listed signals without stating an order verified Instagram Ranking Explained, 2023-05-31 (updated since). Only in Explore is information about the post itself ranked No. 1; in the others, user activity is ranked No. 1.

Surface Order of importance
Feed Your activity → Information about the post → Information about the person who posted → Your history of interacting with someone
Explore Information about the post → Your activity in Explore → Your history of interacting with the person who posted → Information about the person who posted
Reels Your activity → Your history of interacting with the person who posted → Information about the reel → Information about the person who posted
Stories Viewing history → Engagement history → Closeness (no order stated)
  • Only in Explore is "information about the post itself" No. 1. In the others, user activity is No. 1.
    • On unconnected surfaces there is almost no (user, author) relationship history, so item features necessarily carry more weight inferred.
  • In Reels, "history of interacting with the author" is No. 2, but in Explore it is No. 3. These are both unconnected surfaces, yet the order differs.
  • Facebook has never disclosed this kind of per-surface signal order. Instead it presents only "3 levels of usage frequency" (most/occasionally/less frequently), which is covered in facebook.md. The two services disclose the same kind of information along different axes.

Ultra-long user history — DV365

DV365 summarizes a single user's very long interaction history into offline embeddings and feeds them to multiple models in Instagram and Threads verified DV365: Extremely Long User History Modeling at Instagram, KDD 2025 (arXiv 2025-05-31, Meta/Instagram authors).

  • The encoded history is up to 70,000 interactions, 40,000 on average verified. The explicit timeline is max 35K/avg 10K, and the implicit one is max 35K/avg 30K.
  • Instead of lengthening the sequence during training, it uses offline embedding verified.
    • It builds 200 pooled embeddings by pooling per subsequence ("multi-slicing and summarization").
    • These are compressed with the Funnel Summarization Architecture.
  • A single upstream model feeds 15 product models across Instagram and Threads verified. It is used for both retrieval and ranking in Reels/Feed/Explore/Stories.
  • The refresh interval is 6 hours verified. After quantization, the stored form is 58×17 long integers, compressed from 200×256 fp32.
  • In the online result, Instagram app-wide time spent rose +0.7% verified.
    • NE (normalized entropy) on Reels ranking tasks improved by 0.4% or more on average.
    • Retrieval hit rate improved by 2–8%.
  • The paper says it has been validated in production for over 1 year since its first launch verified: "production battle-proven for >1 year since our first launch".
  • It claims to be incremental even when applied on top of existing attention-family sequence models (including HSTU) verified. The argument is that attention shows diminishing returns at a length of 40K.

inferred Instagram is the reference surface within Meta for "ultra-long history." The HSTU paper anonymized the surface (facebook.md open question 5), but DV365 names Instagram in its title. Details are in topics/sequence-transformer-ranking.md.

Model operating scale — only Instagram disclosed it

Instagram disclosed that it runs more than 1,000 ML models in production verified Journey to 1000 models: Scaling Instagram's recommendation system, 2025-05-21. The model naming convention shows a separate MTML model for each surface and component verified.

  • There are more than 1,000 ML models in production verified. There are more than 10 launches per week: "more than 10 launches per week".
  • The funnel layer names are settled here verified: Sourcing → Early-stage ranking (ESR) → Late-stage ranking (LSR)
  • The model naming convention was published verified. It is direct evidence that there is a separate MTML model for each surface × component.
    • ig_stories_tray_mtml = ig (app) / stories (surface) / tray (Stories tray) / mtml (multi-task-multi-label)
  • The infrastructure the post covers is as follows verified.
    • Model Registry (based on Configerator)
    • Automated launch workflow ("from days to hours")
    • Model Stability Metric: generates SLOs from calibration and normalized entropy.
    • Offline evaluation based on recorded-traffic replay
    • Team-level capacity quotas

inferred The real subject of this post is not ranking but the organizational problem of "running 1000 ranking models." Instagram is the only side where Meta has disclosed this layer.

Re-ranking, diversity, and filters

Instagram's official sentence about trying not to show too many posts from the same person in a row has no numbers verified (myth check). In contrast, diversity at the retrieval stage is disclosed concretely as round-robin per seed account verified (retrieval DSL). Policy filters are confirmed in two layers: a score threshold inside retrieval and the filtering described in the DSA filing verified (policy filters). Accounts that mainly repost others' content do not get recommended verified (originality), and accounts that often share age-inappropriate content are not recommended to teens verified (teens).

"Blocking 3 in a row from the same account" is wrong — myth check

The widely repeated claim that "Instagram blocks 3 or more consecutive posts from the same account" has no Meta primary source. Mosseri's actual sentence has no number. The actual sentence is as follows verified Instagram Ranking Explained, 2023.

"we try to avoid showing too many posts from the same person in a row, or too many suggested posts back to back"

  • The wording is only "too many" and "try to avoid", so there is no threshold and it is not a hard constraint.
  • The same sentence states two separate constraints.
    • One is consecutive content from the same author.
    • The other is consecutive suggested (unconnected) posts. Facebook has no corresponding statement.
  • The only diversity sentence on the IG Feed card also has no number observed 2026-08-09 (1 body passage in the ig-feed card).
    • Card sentence: "The system also tries to ensure your feed has a balanced mix of content types."
    • This sentence is actually less specific than "you wouldn't see multiple video posts in a row" on the Facebook Feed card.
  • In contrast, diversity at the retrieval stage is disclosed concretely. It is diversify_by(seed_id, method=round_robin) in the 2020 query in the retrieval DSL section.
    • Instagram's diversity handling may rely mainly on seed round-robin at the candidate generation stage rather than reordering after ranking inferred.

Policy filters — two layers: score threshold and policy document

Instagram's policy filters are confirmed in two layers verified. Retrieval contains a model score threshold, and the DSA filing says the system typically first builds a content inventory and then filters out content that potentially violates policy verified.

  • There is a model threshold filter inside retrieval verified 2020 query: filter(non_recommendable_model_threshold=0.2).
  • The DSA filing says the system typically first builds an inventory of available content and then filters out content that potentially violates policy verified Instagram Systemic Risk Assessment (assessment period 2023-09–2024-08).
    • Original text: "Our systems typically first produce an inventory of available content and then filter it to remove content that potentially violates our policies."
    • ⚠ The URL linked here is a report hub page, not a permalink to the quoted document itself. The 4 verbatim quotes in this section cannot be re-verified without a direct link to the document (2026-08-09).
  • On sensitive topics, it reduces the role of shares and comments in distribution verified same source: "We reduce this risk by limiting the role of shares and comments in the distribution of sensitive topics."
    • The same sentence recorded in facebook.md also appears in the Instagram report. This means that varying signal weights by topic is a policy common to Meta.
  • The same source lists measures for teens as follows verified: "under 18 age gating, probable violation demotions on feed, age based filtering on recommended surfaces and hashtag filtering".
  • The number of recommender system cards stated in the same source matches the number of Instagram cards in the index viewed on 2026-08-09 verified: "10 recommender 'System Cards'".

Originality — Instagram applied it earlier and more strongly than Facebook

Accounts that mainly repost others' content do not get recommended verified Rewarding original creators on Instagram, current page last updated 2026-04-30. The scope of this policy was expanded from Reels to Photos and Carousels verified.

  • The criteria for judging originality are as follows verified.
    • Content the creator filmed or produced directly
    • Their own edited compilations and guides
    • 3rd-party content with meaningful modifications ("meaningful modifications")
  • An account can be recommended again if most of its posts in the last 30 days are considered original verified. This is the recovery condition.
    • This criterion is a rolling window, so it is based on the content composition of the last 30 days, not on a point in time such as "30 days since the last violation."
    • The status can be checked in Account Status.
  • We could not confirm the specific threshold of "10 or more reposts within 30 days" from a primary source inferred. It appears repeatedly in secondary reporting, but we could not confirm it in the body of the current Meta page. Always mark it as unconfirmed when quoting.

This policy pairs with open question 10 in facebook.md (the 2026-03 Facebook original-creator rewards). Instagram applied it first (2024) and Facebook followed inferred.

Teens — recommendation eligibility itself is restricted by age

Meta wrote that teens should not see content that goes against the updated guidelines in recommendation surfaces, Feed, and Stories, even when shared by an account they follow verified New PG-13 Guidelines for Instagram Teen Accounts, 2025-10-14.

"Teens shouldn't see content that goes against our updated guidelines in recommendations (Explore, Reels, and in-Feed), Feed, and Stories — even when shared by someone they follow."

  • It also applies to content from accounts they follow verified. This is a filter that crosses the boundary between connected and unconnected content.
  • There is also an account-level filter verified. Teens cannot follow accounts that often share age-inappropriate content, those accounts are not recommended to teens, and they become harder to find in search.
    • "Teens will no longer be able to follow accounts that we've found regularly share age-inappropriate content"
    • "We won't recommend these accounts to teens, and we'll make it harder for teens to find these accounts in Search."
  • It blocks teens from seeing content results for a wider range of adult search terms verified: "We'll block teens' ability to see content results for a wider range of mature search terms, such as 'alcohol' or 'gore'."
  • The claim that the MPA (Motion Picture Association) demanded that the use of the "PG-13" name stop was confirmed only through secondary reporting inferred.
    • There are signs that the name changed to "13+" in a follow-up announcement in 2026-04. That announcement is Instagram Expands Teen Accounts Inspired by 13+ Content Ratings, and we have not yet been able to read it.

Cold start

New-user cold start has no primary source found for Facebook and is disclosed only for Instagram (new users). For users with sparse engagement history, seeds are built by expanding the graph through the accounts they liked to the accounts those accounts follow verified (new users). We found no Instagram-specific primary source for new content (new content).

New users — a disclosure that Facebook does not have is here

For users with sparse engagement history, seeds are built with one-hop and two-hop graph expansion verified Designing a Constrained Exploration System, 2020.

  • The seed path runs through the accounts user A liked, to the accounts those accounts follow verified.
    • A → Account Liked by A → Accounts followed by the accounts A likes (Seed Accounts)
  • facebook.md ends with "Facebook new-user cold start = no primary source found". Only the Instagram side is disclosed.
  • The supporting system is Suggested Accounts verified (ig-suggested-accounts). The features the card discloses are all graph features, and content embeddings are not in the list.
    • "How many mutual friends do you and the suggested accounts have on Instagram"
    • "How many popular followers do suggested account have"
    • "Whether the suggested account is following you"
    • "How long the suggested account has been following you"
    • "How many follows have you made in the last 28 days"
  • Instagram replaces the new-user problem with "which accounts should we get them to follow" rather than "which content should we show" inferred. This is because all 5 prediction heads on the Suggested Accounts card are follow and follow-back.

Feedback signals

Instagram has negative actions as prediction heads with different names on each surface, and put a negative term in the value model formula as well verified (negative heads). Your Algorithm, which lets users adjust recommendations by topic, applies to all of Instagram including Feed, Reels, and Explore, as of the announcement post (updated through 2026-06-10) verified (Your Algorithm).

Negatives exist as prediction heads — with different names on each surface

Negative actions are included as prediction heads with different names on each surface verified. Explore predicts "Not Interested" clicks, Reels Chaining predicts watching for less than 3 seconds, and Stories predicts exiting the current story verified. All phrases in the table below are quotes copied verbatim from each card.

Surface Negative head
Explore "How likely you are to click 'Not Interested' on a post"
Reels Chaining "How likely you are to watch less than three seconds of a reel"
Feed "How likely you are to skip this post", "How likely you are to skip over the first post in feed"
Stories "How likely you are to tap exit the current story"
Feed Recommendations "How likely you are to skip over the first post in feed"
  • The value model formula itself includes negatives verified.
    • 2020 formula: (1 - P(not_interested))^w
    • 2023 formula: – W_see_less * P(see less)
  • Facebook discloses the existence of negative predictions only in the body text of the Transparency Center. The statement is that hide/snooze/report/angry lower the distribution. In contrast, Instagram disclosed them explicitly as terms in the formula.
    • This is the clearest example of the difference in disclosure level between the two services inferred.
  • The way negative signals are stored is also visible verified. Reels Chaining keeps a list of authors watched for less than 3 seconds as a feature: "The authors of reels you've spent less than three seconds watching".

DM share (send) is a prediction head

The Feed card has DM sharing as a prediction head, and the Reels Chaining card has sharing off Instagram and resharing as prediction heads verified.

  • ig-feed: "How likely you are to share a post with someone in a direct message"
  • ig-reels-chaining: "How likely you are to share a reel off of Instagram", "How likely you are to reshare a reel"
  • These two sentences are the primary evidence that "sends" is a ranking target.
  • The widely quoted "3 most important signals = watch time / sends per reach / likes per reach" (2025-01 Mosseri) originates from Mosseri's Instagram video post, and we could not obtain a primary text URL inferred. It rests on secondary reporting.
    • The multiplier "sends are weighted 3–5× likes" does not appear in any Meta document, so it must not be cited.
  • However, the direction matches the cards verified. DM shares and external shares each exist as separate prediction heads.

User control — Your Algorithm

Your Algorithm shows a summary of the topics influencing recommendations and lets users tell it in free text what they want to see more or less of verified Control Your Instagram Reels Algorithm. It was first released in US Reels on 2025-12-10 and later expanded on 2026-04-15 and 2026-06-10 verified.

  • As of the announcement post, the scope is all of Instagram, including Feed, Reels, and Explore verified: "Your Algorithm is now live across all of Instagram, including Feed, Reels, and Explore."
  • The dashboard shows an AI summary of the topics influencing recommendations verified: "View an AI-generated summary of the topics influencing the posts and recommendations you see".
  • Individual posts get an interest label verified. Example: "From Running".
  • Controls are entered as free text verified: "tell us what you want to see more or less of, or add new topics entirely".
  • Update speed is not public observed 2026-08-09. The corpus inspected was 1 body passage of the announcement post above, and unlike Threads Dear Algo, it has no time-window wording.
  • The model is not public. The original text says only "AI".

Regulation — ongoing as of 2026

On 2026-07-10, the EC (European Commission) preliminarily found that the addictive design of Instagram and Facebook breaches the DSA verified Commission preliminarily finds the addictive design of Instagram and Facebook in breach of the Digital Services Act, 2026-07-10. The scope of the investigation includes infinite scroll, autoplay and push notifications, together with highly personalized recommender systems verified.

  • Original text of the investigation scope: "features such as infinite scroll, autoplay, push notifications, and the platforms' highly personalised recommender systems"
  • The preliminary finding is, in essence, that Meta did not adequately assess the risks of its addictive design and that its current mitigation measures did not respond effectively to those risks verified.
    • "Meta did not adequately assess the risks of its addictive design on the physical and mental wellbeing of users, including minors and vulnerable adults."
    • "Meta's current mitigation measures failed to effectively tackle the risks stemming from its addictive design."
  • The required remedies are reported as "autoplay and infinite scroll off by default, screen-time breaks, and a change to recommendations that are less engagement-focused", but we could not confirm that sentence in the body of the EC press release inferred. This is based on secondary reporting.
  • The penalty cap is 6% of global revenue inferred. This too comes from secondary reporting.

The most important point in this note is that the infinite-scroll-based funnel and the session-duration prediction head described above are exactly what the EC objects to. The session-duration head is the Feed card's How likely the first post you see is to keep you spending time in your Feed during this session. inferred Regulatory pressure could become the first case that changes a ranking objective function, so it is highly worth tracking.

Open questions

These are questions that remained unanswered as of the last update of this file (2026-08-09).

  1. Is the 2020 multiplicative → 2023 additive change an actual transition? The surfaces differ (Suggested Posts vs Explore), and no source compares before and after on the same surface.
    • The 2026-10-20 paper writes that the Feed VM is a weighted sum in which some groups of terms are multiplied verified. This means the two forms can coexist within one VM, and it did not disclose which terms are multiplied.
  2. What are the actual scales and signs of W_click, W_like and W_see_less? Only the symbolic formula is public.
    • The 2026-10-20 paper also writes the weight values of the original and increment terms only as "production weight" and did not disclose the numbers verified.
  3. Why is there no ig-reels card? Meta did not disclose why no system card exists that covers the whole Reels tab.
  4. Exactly how many prediction heads does each card have? On some surfaces the extraction result disagrees with the count stated on the card (Feed, Stories, Reels Chaining, Suggested Accounts). A recheck is needed.
