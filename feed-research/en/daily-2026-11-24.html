1A ranking model that builds ratio features itself — VK

Source Deep Cross-Division Network for Product-and-Ratio Feature Interactions in Industrial Ranking — AI VK, 2026-11-20 v1 (accepted at WSDM '27), paper.

Background Industrial rankers often learn feature crosses (multiplying two features to create a new signal) with DCN-family blocks (Deep & Cross Network, a structure that stacks cross layers to learn feature products automatically). However, the cross layers of DCN and DCNv2 can only produce non-negative integer powers of features, so ratios such as click-through rate or normalized counts must be computed by hand and fed in as inputs. This paper adds a division branch to the cross layer so the model builds such ratio features directly.

What we learnedA. A cross layer with a division branch replaced handcrafted ratio features and also raised engagement metrics

  • DCDN adds a division branch to a DCNv2-style cross layer and learns products, ratios, and mixed crosses together verified — arXiv abstract
    • The paper formalizes the expressible crosses as multivariate Laurent polynomials (polynomials that also allow negative powers).
    • It says a K-layer DCDN produces monomials up to ℓ1 degree K+1, with signed degrees from −K to K+1.
  • Replacing the DCNv2 block of the baseline model with DCDN allowed all handcrafted ratio features to be removed from the input, and the number of input features fell by 40.1% verified — same abstract
  • It says that, deployed in the production ranker of a large short-video service, it gained +3.25% likes and +16.26% shares in an online A/B test verified — same abstract
    • It reports total view time (TVT) of +0.33% and clicks to open fullscreen of +0.38%, all statistically significant.
    • The number of videos shown fell by 0.24%.
  • All 5 authors are affiliated with AI VK, and 2 of them also list Lomonosov Moscow State University verified — HTML version
  • The service tested is likely VK's short-video surface inferred — the evidence is the author affiliation and the VK-LSVD evaluation dataset; the paper does not name the service.

"DCDN is deployed in the production ranking stack of a major short-video service. In a live A/B test on this service, DCDN increased likes by $3.25%$, shares by $16.26%$, total view time (TVT) by $0.33%$, and clicks to open fullscreen by $0.38%$; all changes were statistically significant." — Deep Cross-Division Network for Product-and-Ratio Feature Interactions in Industrial Ranking (paper), 2026-11-20

Canon update This is not a source for a tracked service, so we did not change the canon; we added an entry to new this month in radar.md.

Why it matters This gives one production data point that widening the expressiveness of the feature-cross block can move a class of feature engineering into the model. The rise in shares is much larger than in the other metrics, but the abstract alone does not explain why.
