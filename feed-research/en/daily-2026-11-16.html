1A sort-selection test was added to the Following feed — Reddit

Source Changelog - November 10, 2026 — Reddit Help Center, 2026-11-10 (edited the same day), change log.

Background On 2026-10-28, Reddit announced a redesign that splits the home feed into two tabs: For You (a feed mixing posts from joined communities with interest-based recommendations) and Following (a feed of posts from joined communities). The announcement did not disclose how either feed is ordered, and the 2026-09-10 change log said Following also includes posts from followed users, which differed from the announcement's definition. For that reason, this repository's Reddit canon had kept the sorting of both feeds and the scope of Following as open questions. This change log states the rollout start date and the scope of Following, and announces several experiments such as Following sort selection and a Popular tab.

What we learnedA. Following contains only posts from joined communities, and some users choose the sort themselves

  • Some users can choose Hot, Top, Best, or New sorting in Following on desktop and mobile web verified — change log 2026-11-10
    • The app is not included in the test, and the change log does not state the default sort.
    • Hot, Top, Best, and New are the existing sort names used on community pages. It does not say that sort selection is being added to For You.
  • It says Following shows only posts from joined communities, which now matches the newsroom definition verified — same change log
    • The only remaining document that says posts from followed users are also included is the 2026-09-10 change log.
  • The For You and Following rollout began on 2026-10-27 for users in all regions on iOS, Android, and reddit.com verified — same change log
    • The feed visited last becomes the default feed on the next launch. An experiment renaming the For You tab to Discover or Explore is also being run.

"Following will only show you content from communities that you have joined. You can switch between feeds at any time, and whichever feed you last visit will be your default. Some users will start to see sorting options on their Following feeds, like Hot, Top, Best, and New, on desktop and mobile web." — Changelog - November 10, 2026, 2026-11-10

What we learnedB. The Popular tab and the home-feed video carousel are tested separately

  • Starting 2026-10-27, an experiment shows Popular (the list of recently popular posts that is the default feed for logged-out users) as a tab next to Following for a small group of users on iOS and Android verified — same change log
  • A carousel (a feed module that collects several items in one row to swipe sideways) of recommended videos inside the home feed is being tested on iOS and Android verified — same change log
    • The change log does not state how the videos for the carousel are chosen.
  • A test has also started that adds Business, Technology, Entertainment, Sports, Science, and Health topic filters above the News feed for some users verified — same change log

What we learnedOther changes

  • A logged-in-only test in some markets outside the US starts in November and prompts logged-out visitors to log in, sign up, or use the app verified — same change log
  • For public communities with archiving turned on, the period after which posts are archived automatically is extended from 6 months to 18 months. Until then, comments and votes remain possible on older posts verified — same change log
  • Reddit Reviews, which gathers product conversations and shows them with an AI summary, is rolling out in the US over several weeks. It is a search-surface feature, so it was not folded into the canon verified — same change log

Canon update In services/reddit.md, the rollout sentence in the ## Feed surfaces introduction was corrected to a 2026-10-27 start, and the Following row's sort cell and reference in the table were corrected. In the For You and Following section, bullets were added for the rollout, Following sort selection, the Popular tab, the video carousel, and the News topic filters, and the sub-bullet saying the definitions differ was revised to match the new change log. A bullet on when the logged-in-only test starts was added to the logged-out users section, a bullet on sort selection and the scope of Following to item 3 of ## Open questions, and this change log to ## Sources.

Why it matters Following appears to be moving back to the existing sorts that users choose, leaving only For You as the recommendation feed inferred. The evidence is that sort selection was attached only to Following, and that the scope of Following is now confirmed as joined communities. The default sort of both feeds is still not public, so open question 3 stays.

2Diversity re-ranking started receiving recent impression history — X

Source xai-org/x-algorithm@30647a8 — xAI, 2026-11-14, code. In this repository's numbering it is Gen4+64 (Gen4+N is the number these notes assign in order to commits after the 2026-08-13 Gen4 release).

Background After ranking finishes, X For You re-selects the slate with DPP (determinantal point process, a diversity technique that selects at the set level so similar items are not picked together). This computation is done not by home-mixer (the service that receives feed requests, gathers candidates, and scores them) but by a separate service, VMRanker (vm-ranker, the service that computes the weighted sum and DPP re-ranking). The 2026-11-13 commit (Gen4+63) added, off by default, a sliding-window mode that suppresses candidates similar to the few posts directly above, and this mode uses the history of posts served within the previous 10 minutes as its leading part. This commit reflects the 2026-11-13 sync (a cron mirror that copies production settings into the repository code) and turned on the switch by which home-mixer sends that history.

What we learnedA. The history is now sent, but the mode that reads it is off, so the order is unchanged

  • The switch by which home-mixer sends the previous impression history to VMRanker changed from false to true, and the maximum count dropped from 200 to 50 verified — home-mixer/params/param.rs:633-643
    • The parameters are VMRankerSendDppHistory (rust_home_mixer_vm_ranker_send_dpp_history) and VMRankerDppHistoryMaxItems.
    • The sync timestamp in the file header changed from 2026-11-12T16:00:36Z to 2026-11-13T16:00:28Z.
  • VMRanker puts the history into the candidate-selection context only when a window size is set verified — vm-ranker/dpp.rs:106-113
    • In the vm-ranker mirror of the same commit, DppWindow is still 0 (off), DppWindowHalfDistance is still 0.0, and DppGreedyOrder is still false (vm-ranker/params.rs:260-272).
  • This appears to be a step that turns on history sending before turning on the window mode, to check request size and latency inferred. The evidence is that only the sending side was turned on while the reading side stays off, and that the cap was lowered from 200 to 50.

What we learnedOther changes

  • grox (a Grok-based nearline classifier that attaches safety comments to posts) gained an option that, for posts with 5 or more images, joins the images horizontally in X display order and sends them to the LLM together. It is off by default verified — grox/core/data_loaders/media_loader.py
    • The switch is enable_combined_view, and the joined image is not created if its width exceeds 3× its height. The prompt says this is meant to judge posts where one picture was cut into several images and uploaded.
    • The screenshot v2 path, which was off by default, was deleted in the same commit.

Canon update In services/x.md, in the VMRanker DPP item of the diversity section, the reference commit of the off-by-default sentence was corrected to 30647a8, and a sub-bullet was added saying history sending is on by default (up to 50 items) but the window mode is off, so the order is unchanged. The reference commit and commit count in ## Sources were raised to 30647a8 and 64, one row was added to the reference commit table, and one row to the change log summary table.

Why it matters This commit does not change the For You order. The evidence is that the window mode that reads the history is still 0 in the vm-ranker mirror. However, because the sending side was turned on first, once DppWindow changes to a value other than 0 in a later sync, "diversity among posts that appear consecutively on screen" will actually apply.
