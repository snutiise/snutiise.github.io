1Following 피드에 정렬 선택 시험이 붙었다 — Reddit

자료 Changelog - November 10, 2026 — Reddit Help Center, 2026-11-10(같은 날 수정), 변경 이력.

배경 Reddit은 2026-10-28 홈 피드를 For You(가입한 커뮤니티 글과 관심사 기반 추천을 섞는 피드)와 Following(가입한 커뮤니티 글 피드) 두 탭으로 나누는 개편을 발표했다. 발표문은 두 피드의 순서를 어떻게 정하는지 밝히지 않았고, 2026-09-10 변경 이력은 Following에 팔로우한 사용자의 글도 들어간다고 적어 발표문과 정의가 달랐다. 그래서 이 저장소의 Reddit 정본은 두 피드의 정렬과 Following의 범위를 열린 질문으로 두고 있었다. 이번 변경 이력은 롤아웃 시작일과 Following의 범위를 밝히고, Following 정렬 선택과 Popular 탭 같은 실험 몇 가지를 알렸다.

새로 알게 된 것A. Following은 가입한 커뮤니티 글만 담고, 일부 사용자는 정렬을 직접 고른다

  • 일부 사용자는 데스크톱과 모바일 웹의 Following에서 Hot, Top, Best, New 정렬을 직접 고를 수 있다 확인 — 변경 이력 2026-11-10
    • 앱은 대상에 없고, 기본 정렬이 무엇인지는 적지 않았다.
    • Hot, Top, Best, New는 커뮤니티 페이지에서 쓰던 기존 정렬 이름이다. For You에 정렬 선택이 붙는다는 말은 없다.
  • Following은 가입한 커뮤니티 글만 보여 준다고 적어, 뉴스룸 정의와 같아졌다 확인 — 같은 변경 이력
    • 팔로우한 사용자의 글도 들어간다고 적은 문서는 2026-09-10 변경 이력 하나로 남았다.
  • For You·Following 롤아웃은 2026-10-27 iOS, Android, reddit.com의 모든 지역 사용자에게 시작됐다 확인 — 같은 변경 이력
    • 마지막으로 연 피드가 다음 실행의 기본 피드가 된다. For You 탭 이름을 Discover나 Explore로 바꿔 보는 실험도 함께 연다.

"Following will only show you content from communities that you have joined. You can switch between feeds at any time, and whichever feed you last visit will be your default. Some users will start to see sorting options on their Following feeds, like Hot, Top, Best, and New, on desktop and mobile web." — Changelog - November 10, 2026, 2026-11-10

새로 알게 된 것B. Popular 탭과 홈 피드 영상 캐러셀을 따로 시험한다

  • 2026-10-27부터 iOS와 Android의 소수 사용자에게 Popular(로그아웃 사용자의 기본 피드인 최근 인기 글 목록)를 Following 옆 탭으로 보여 주는 실험을 연다 확인 — 같은 변경 이력
  • 홈 피드 안에 추천 영상을 가로로 넘겨 보는 캐러셀(여러 항목을 한 줄에 모아 옆으로 넘기는 피드 모듈)을 iOS와 Android에서 시험한다 확인 — 같은 변경 이력
    • 캐러셀에 넣을 영상을 고르는 방식은 적지 않았다.
  • 일부 사용자의 News 피드 위에 Business, Technology, Entertainment, Sports, Science, Health 토픽 필터를 붙이는 시험도 시작됐다 확인 — 같은 변경 이력

새로 알게 된 것그 밖의 변경

  • 미국 밖 일부 시장의 로그인 전용 시험은 11월에 시작하고, 로그아웃 방문자에게 로그인, 가입, 앱 이용을 권한다 확인 — 같은 변경 이력
  • 아카이브를 켠 공개 커뮤니티에서 글이 자동 보관되는 기간이 6개월에서 18개월로 늘어난다. 그동안 오래된 글에도 댓글과 투표를 할 수 있다 확인 — 같은 변경 이력
  • 상품 대화를 모아 AI 요약과 함께 보여 주는 Reddit Reviews가 미국에서 몇 주에 걸쳐 롤아웃된다. 검색 지면 기능이라 정본에는 반영하지 않았다 확인 — 같은 변경 이력

정본 반영 services/reddit.md ## 피드 지면 도입의 롤아웃 문장을 2026-10-27 시작으로 고치고, 표의 Following 행 정렬 칸과 기준을 고쳤다. For You와 Following 절에 롤아웃·Following 정렬 선택·Popular 탭·영상 캐러셀·News 토픽 필터 불릿을 더하고, 정의가 다르다는 하위 불릿을 새 변경 이력에 맞게 고쳤다. 로그아웃 사용자 절에 로그인 전용 시험의 시작 시점 불릿을, ## 열린 질문 3번에 정렬 선택과 Following 범위 불릿을, ## 출처에 이 변경 이력을 더했다.

의미 Following은 사용자가 고르는 기존 정렬로 돌아가는 방향이고, For You만 추천 피드로 남는 구조로 보인다 추정. 근거는 정렬 선택이 Following에만 붙었고, Following의 범위가 가입 커뮤니티로 확정됐다는 점이다. 두 피드의 기본 정렬은 여전히 공개되지 않았으므로 열린 질문 3번은 남겨 둔다.

2다양성 재순위에 최근 노출 이력을 싣기 시작했다 — X

자료 xai-org/x-algorithm@30647a8 — xAI, 2026-11-14, 코드. 이 노트들이 붙인 번호로는 4세대+64다(4세대+N은 이 노트들이 2026-08-13 4세대 공개 뒤의 커밋에 차례로 붙인 번호다).

배경 X For You는 랭킹이 끝난 뒤 DPP(determinantal point process, 서로 닮은 항목이 함께 뽑히지 않게 집합 단위로 고르는 다양성 기법)로 슬레이트를 다시 고른다. 이 계산은 홈믹서(home-mixer, 피드 요청을 받아 후보를 모으고 점수를 매기는 서비스)가 아니라 별도 서비스 VMRanker(vm-ranker, 가중합과 DPP 재순위를 계산하는 서비스)가 한다. 2026-11-13 커밋(4세대+63)은 바로 위 몇 자리 포스트와 닮은 후보를 누르는 슬라이딩 윈도 모드를 기본 off로 더했고, 이 모드는 직전 10분 안에 내보낸 포스트 이력을 앞부분으로 쓴다. 이번 커밋은 2026-11-13 sync(프로덕션 설정을 저장소 코드에 옮겨 적는 크론 미러)를 반영하면서 홈믹서가 그 이력을 싣는 스위치를 켰다.

새로 알게 된 것A. 이력은 이제 실리지만, 읽는 모드가 꺼져 있어 순서는 그대로다

  • 홈믹서가 직전 노출 이력을 VMRanker에 싣는 스위치가 false에서 true로 바뀌었고, 최대 개수는 200에서 50으로 줄었다 확인 — home-mixer/params/param.rs:633-643
    • 파라미터는 VMRankerSendDppHistory(rust_home_mixer_vm_ranker_send_dpp_history)와 VMRankerDppHistoryMaxItems다.
    • 파일 헤더의 sync 시각은 2026-11-12T16:00:36Z에서 2026-11-13T16:00:28Z로 바뀌었다.
  • VMRanker는 윈도 크기가 설정됐을 때만 이력을 후보 선택 맥락에 넣는다 확인 — vm-ranker/dpp.rs:106-113
    • 같은 커밋의 vm-ranker 미러에서 DppWindow는 0(off), DppWindowHalfDistance는 0.0, DppGreedyOrder는 false 그대로다(vm-ranker/params.rs:260-272).
  • 윈도 모드를 켜기 전에 이력 전송을 먼저 켜서 요청 크기와 지연을 확인하는 단계로 보인다 추정. 근거는 이력을 읽는 쪽이 꺼진 채 보내는 쪽만 켜졌고, 상한을 200에서 50으로 낮췄다는 점이다.

새로 알게 된 것그 밖의 변경

  • grox(Grok 기반으로 포스트에 안전 주석을 다는 nearline 분류기)에 이미지 5장 이상인 포스트의 이미지를 X 표시 순서대로 가로로 이어 붙여 LLM에 함께 보내는 옵션이 생겼다. 기본 off다 확인 — grox/core/data_loaders/media_loader.py
    • 스위치는 enable_combined_view이고, 이어 붙인 이미지의 가로가 세로의 3배를 넘으면 만들지 않는다. 한 장을 여러 이미지로 잘라 올린 포스트를 판정하려는 것이라고 프롬프트에 적혀 있다.
    • 같은 커밋에서 기본 off였던 스크린샷 v2 경로는 삭제됐다.

정본 반영 services/x.md 다양성 절의 VMRanker DPP 항목에서 기본 off 문장의 기준 커밋을 30647a8로 고치고, 이력 전송이 기본 on(최대 50개)이지만 윈도 모드가 꺼져 순서가 그대로라는 하위 불릿을 더했다. ## 출처의 기준 커밋과 커밋 수를 30647a8, 64개로 올리고 기준 커밋 표에 한 행을, 변경 이력 요약표에 한 행을 추가했다.

의미 이번 커밋으로 For You 순서는 바뀌지 않는다. 근거는 이력을 읽는 윈도 모드가 vm-ranker 미러에서 여전히 0이라는 점이다. 다만 보내는 쪽이 먼저 켜졌으므로 다음 sync에서 DppWindow가 0이 아닌 값으로 바뀌면 "화면에 이어 보이는 포스트끼리의 다양성"이 실제로 적용된다.
