{%- comment -%} Disqus 는 '댓글 보기' 버튼을 눌렀을 때만 불러온다. 누르기 전에는 서드파티 요청이 0건이다. 예전에는 window.onscroll 로 '바닥 근처'에서 자동 로드하려 했지만 main.css 의 html,body height 100% 때문에 body.offsetHeight 가 뷰포트 높이로 고정돼 첫 1px 스크롤에 로드됐다. 그래서 글을 조금만 읽어도 무료 플랜이 끼워 넣는 LiveIntent 신원추적·VigLink 제휴링크 스크립트(135KB 이상, iframe 7개)를 받았고, 코드 블록 안 URL 이 제휴 링크로 바뀌었다. 설정은 Disqus 가 실제로 읽는 전역 disqus_config 로 넘긴다. 예전 disqus_title, disqus_url 은 함수 안 지역 변수라 전달되지 않았고, title 은 Liquid 에 없는 replace 메서드라 늘 빈 값이었다. 값은 jsonify 로 넣는다. 따옴표로 감싸 넣던 page.url 이 Floyd's 글에서 문자열을 끊어 SyntaxError 로 이 블록 전체가 죽어 그 글에는 댓글이 아예 안 떴다. page.url 은 절대 URL 로 고정한다. 그래야 쿼리스트링이나 로컬 미리보기 주소로 열어도 같은 스레드를 쓴다. identifier 는 일부러 넣지 않는다. 기존 스레드(dcmacro 16개, chatting-app·github-connect-ssh· html5-desktop-api 각 2개)는 identifiers 가 빈 채 link 로만 묶여 있다(2026-10 확인). identifier 를 새로 주면 Disqus 가 그 값으로 스레드를 찾다 못 찾고 빈 스레드를 새로 만들어 기존 댓글이 떨어진다. identifier 가 없으면 Disqus 는 page.url 을 식별자로 쓴다. 인라인 JS 이므로 // 주석 금지(compress 레이아웃이 줄바꿈을 지운다). {%- endcomment %}
